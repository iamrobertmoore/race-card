# Race Card

A race-day prediction from your own training export, made on your own machine with open models.

Built for my friend Sam, who's racing IRONMAN 70.3 Weymouth next September. Work in progress for the
DEV Hacktoberfest Weekend Challenge (2 to 5 October 2026).

- **TabPFN v2** (Prior Labs, open weights) predicts each leg as a range, from your Strava or Garmin export.
- **Gemma 4** (via Ollama) writes the plan in plain English, using only the numbers it's given.
- Nothing is uploaded. TabPFN v2 is licensed for non-commercial use.
